# 2026 China Statistical Modeling Competition

This folder contains the materials for the 2026 China Statistical Modeling Competition, including the dataset, analysis code, generated figures, LaTeX source files, and final PDFs.

## Structure

- `data/`: raw input data used in the modeling workflow.
- `process/`: Python scripts for preprocessing, descriptive statistics, grey relational analysis, VAR modeling, and mediation analysis.
- `charts/`: generated figures used in the paper.
- `latex & pdf/`: LaTeX source files and paper PDFs.

## Main Files

- Analysis entry points: `process/step*.py`
- Paper source: `latex & pdf/4.19_draft2.tex`
- Paper PDFs: `latex & pdf/4.19_draft2.pdf`, `latex & pdf/final.pdf`
