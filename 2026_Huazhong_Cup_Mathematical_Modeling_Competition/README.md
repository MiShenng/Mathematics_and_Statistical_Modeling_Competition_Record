# 2026 Huazhong Cup Mathematical Modeling Competition

This folder contains the materials for the 2026 Huazhong Cup Mathematical Modeling Competition, including the problem statement, input data, analysis code, plotting code, generated figures, LaTeX source file, and final PDF.

## Structure

- `A题：城市绿色物流配送调度/`: problem statement, submission instructions, and attachment files.
- `process/`: data, modeling scripts, requirements, and generated result files.
- `chart_code/`: plotting script used to regenerate the paper figures.
- `charts/`: generated figures used in the paper.
- `latex & pdf/`: LaTeX source file and final paper PDF.

## Main Files

- Analysis entry point: `process/main.py`
- Plotting entry point: `chart_code/generate_all_figures.py`
- Paper source: `latex & pdf/final.tex`
- Final paper PDF: `latex & pdf/面向不确定性的绿色物流配送鲁棒性优化——从绿区限行到实时动态重调度.pdf`
